# Confidence Language

Internal numeric scores may be converted into public confidence language.

| Internal Range | Public Language |
|---|---|
| 0.80–1.00 | High confidence |
| 0.60–0.79 | Moderate confidence |
| 0.40–0.59 | Directional signal |
| Below 0.40 | Watch item / unconfirmed signal |

## Rule

Use confidence language to clarify uncertainty, not to create false authority.
