11 — Reference

Usage Reference

Implementation checklist for new templates. Every page that extends this design system must satisfy these requirements.

Element Implementation Notes
Stylesheet <link rel="stylesheet" href="notitia/notitia.css"> Required on every page. Imports Google Fonts, all custom properties, and base component classes.
Body class <body class="nc"> Activates serif base, resets, and background. Without this, token-dependent styles will not render correctly.
Series accent body { --nc-accent: var(--nc-sienna); } Override --nc-accent at body level in a page <style> block or inline. Default is --nc-ochre.
Card annotation <!-- @dsCard group="Notitia Civica" name="…" subtitle="…" --> HTML comment on line 2 registers the file in the design project card index. Required for all files in the group.
Kicker <div class="nc-kicker">Series Name</div> Use above headlines for quick series identification and consistent hierarchy.
Rail <div class="nc-rail">...</div> Use for metadata, dates, and compact editorial signals.
